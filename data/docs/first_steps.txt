TITLE: First Steps

SOURCE: https://fastapi.tiangolo.com/tutorial/first-steps/

CATEGORY: Fundamentals

CONTENT:

OVERVIEW:
FastAPI is a Python framework used to build APIs. A basic FastAPI application starts by importing the FastAPI class, creating an application instance, and defining endpoints that handle HTTP requests.

CREATING A BASIC APPLICATION:
To create a basic application:

1. Import FastAPI using: from fastapi import FastAPI
2. Create an application instance using: app = FastAPI()
3. Define an endpoint using a path operation decorator.
4. Create a Python function to handle requests to that endpoint.
5. Return data from the function, commonly as a dictionary that FastAPI converts into JSON.

EXAMPLE CODE:

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}


RUNNING THE APPLICATION:
Save the application in a file named main.py.

Start the development server using:

uv run fastapi dev

The application will run locally, commonly at:
http://127.0.0.1:8000

API DOCUMENTATION:
FastAPI automatically generates interactive API documentation.

- /docs provides interactive documentation through Swagger UI.
- /redoc provides an alternative documentation interface through ReDoc.
- /openapi.json provides the generated OpenAPI schema in JSON format.

IMPORTANT CONCEPTS:

PATH / ENDPOINT:
The URL portion that identifies a resource or functionality, such as /items.

HTTP METHODS:
HTTP methods define the type of action performed on an endpoint.

- GET: Retrieve data.
- POST: Create data.
- PUT: Update data.
- DELETE: Delete data.
- PATCH: Partially update data.

PATH OPERATION DECORATOR:
A decorator such as @app.get("/") connects an HTTP method and URL path to a Python function. Other decorators include @app.post(), @app.put(), and @app.delete().

PATH OPERATION FUNCTION:
The Python function that runs when a request matches the defined path and HTTP method. It can be written using async def or def.

OPENAPI SCHEMA:
A machine-readable description of an API, including its endpoints, parameters, and expected request and response data. FastAPI generates this automatically and uses it to power its API documentation.

KEY TAKEAWAYS:
- FastAPI applications are created using a FastAPI instance.
- Endpoints are defined using decorators and HTTP methods.
- Python functions handle incoming requests and return responses.
- FastAPI automatically converts supported return values, such as dictionaries, into JSON.
- FastAPI generates API documentation and an OpenAPI schema automatically.
